# Ezharakund Waterfalls — Static Site

A static frontend replica of the [Ezharakund Waterfalls](https://github.com/Mrithul-E/Ezharakund_waterfalls_ClientProject) visitor website, built for hosting on **GitHub Pages**.

## Live Site

🌐 **[https://mrithul-e.github.io/Ezharakund_waterfalls_static/](https://mrithul-e.github.io/Ezharakund_waterfalls_static/)**

## About

Ezharakund Waterfalls is a beautiful series of seven natural pools located in Kannur, Kerala. This static site serves as a visitor guide with:

- 🏞️ Photo & video gallery
- 🗺️ Route map and directions
- 🛶 Kayaking activity info
- 👤 Local trail guide contact
- 📱 WhatsApp and phone contact links

## Tech Stack

- HTML5 / CSS3
- Bootstrap 5.3
- jQuery 3.7
- Google Fonts (Manrope, Playfair Display, DM Mono, Noto Serif Malayalam)

No backend, no build step — pure static files served by GitHub Pages.
